# Wuwatappo_Helper

**仅供娱乐使用，创作者概不负责。**

WuwaTappo 1.0.4 的非官方 Windows 辅助修改版本。原程序、角色、配件、表情及界面素材的权利归各自权利人所有。

当前正式版为 **Helper v1.0.4.5**；当前测试版为 **Helper v1.0.4.6 Beta**，适配官方 WuwaTappo v1.0.4。

## 已实现功能

- ✅ **键鼠与手柄映射** — 支持 26 键、鸣潮专属、手柄三种界面，也可切换到输入气泡。支持指定输入范围录制及 TXT 导出。
- ✅ **联机管理** — 可用快捷键切换「仅显示自己」，支持逐人显隐、历史房间，以及横排、纵排和记忆自定义位置。见[联机位置记忆](docs/联机位置记忆.md)。
- ✅ **库存长图与合成提醒** — 按角色、配件和表情分区导出 PNG，附稀有度占比和官方参考概率。可独立开启平阶、升阶提醒。
- ✅ **图鉴试装与表情** — 可在本机试装角色、配件及六槽表情，支持快捷键和按键自动表情。见[图鉴试装](docs/图鉴试装.md)。
- ✅ **i弗TV 专属互动** — BE / HE 两种分支，支持配件动画、道具掉落和可自定义的按键台词。见[i弗TV 说明](docs/i弗TV.md)。
- ✅ **桌面辅助** — 默认显示器、可自定义快捷键与冲突提醒、本地点击数、防连点、延迟 5 秒自动领取宝箱。
- ✅ **低保与轻量版** — 可在余额低于 10000 时自动触发一次本地 `+10000`。Lite 单文件只加入基础辅助功能。
- ✅ **应用内更新** — 官方升版时由 Helper 接管更新提示。从 GitHub 查找匹配的正式版，可选 GH-Proxy 加速下载，校验后安装。
- ✅ **按需运行** — 收起映射时停止补充采集，隐藏的联机桌宠按需卸载图片。见[运行优化说明](docs/按需运行优化说明.md)和[内存测试](docs/内存优化测试说明.md)。

新版设置把 `+10000`、低保、自动开箱和合成提醒放在「基础辅助」，其余设置按用途折叠。联机页集中显示「仅显示自己」、恢复显隐和排列选项。见[界面导航](docs/使用说明.md#新版界面导航)。

## 应用内更新

Helper 版本号的前三段对应官方桌宠版本，第四段是 Helper 的修订号。v1.0.4.3 是首个带应用内更新的版本，v1.0.4.2 及更早版本需要手动替换一次。

- **只更新第四段**。例如 `1.0.4.4` → `1.0.4.5`，完整版可在设置的「程序与更新」点「检查更新」。下载并校验后，点「重启并更新」。轻量版通过上方链接手动更新。
- **官方先升版**。例如官方发布 `1.0.5`，Helper 会接管官方更新提示，等待 GitHub 上前三段匹配的 `1.0.5.X` 正式版。适配版未发布时，当前 Helper 可以继续运行，在线功能以服务器的实际兼容性为准。
- **上次退出前未检查这次升版**。下次启动时自动查 GitHub。如果已经有适配版，后台下载、校验，然后退出桌宠并启动新版。上次已经检查过这次升版，可以在设置里再次手动检查。
- **下载较慢时**。v1.0.4.4 起可在设置的「更新下载源」选「GH-Proxy（尝试）」。选择保存在本机，手动检查和启动时自动更新都会使用。镜像下载或校验失败时会改用 GitHub；检查新版本和读取可信 SHA-256 仍需要访问 GitHub API。
- **下载或安装失败**。设置会提供「去 GitHub 下载」，也可以重试。安装版保留旧文件备份，免安装版把新版保存为同目录下带版本号的 EXE。

## 完整版与轻量版

两个版本都适配官方 WuwaTappo v1.0.4。启动或切换版本前，请从托盘完全退出当前运行的桌宠。

- **完整版**包含基础辅助、联机管理、映射与录制、图鉴试装、库存分享及 i弗TV，支持应用内更新。
- **轻量版**保留官方桌宠功能，Helper 只增加手动 `+10000`、低保、延迟 5 秒自动开箱和平阶／升阶合成提醒。轻量版无需启动 Helper 的键鼠补充采集、SDL3 手柄服务或本地 HTTP 服务。

低保默认关闭。开启后，登录且在线时如果剩余点击数低于 10000，会走现有的本地 `+10000` 流程。每次处于低余额时只加一次，余额恢复到 10000 或以上后才重新等待下一次触发。

## 历史房间与原版图标

房间号旁新增“历史房间”，未进入房间时也可从加入区域打开。按当前账号保存本机成功加入、创建或恢复过的最近 100 个房间，点击 ID 即可进入。已在该房间会提示“你已经在该房间”；在其他房间时先等待退出成功再加入，退出失败会停止操作。账号切换会关闭历史列表并停止后续切换步骤，记录不跨账号混用。

只在服务器返回有效房间成员快照、确认当前账号在房间后记录；无效、已满或关闭的房间仍由官方接口校验。历史保存在本机应用偏好中，不从服务器追溯旧记录，也不会随单 EXE 分享给别人。详细行为见[使用说明](docs/使用说明.md#历史房间)。

已补回 EXE 的原版六档图标（16/24/32/48/64/256 像素），安装程序与安装后的快捷方式也使用原版图标。构建时从原件提取，逐帧核验，避免再次丢失。

## 手柄显示与录制

新增完整手柄外形的交互显示：十字键、面键、肩键、双摇杆和扳机放在对应位置，沿用桌宠的暖色圆润画风。Share / Options 在图上简写为 − / ≡，悬停提示与 TXT 保留完整名称。设备校准和诊断收在“选项”。

- 点击键盘工具栏的“手柄”，支持 Xbox、PS、Nintendo、通用布局；按键按下/松开高亮，双摇杆二维位置、扳机进度实时显示。
- SDL3 接入 XInput、PS HID 和通用摇杆，按实际连接模式适配北通鲲鹏/阿修罗、飞智、盖世小鸡、八位堂等设备；支持热插拔和设备选择。
- 保留同一轮采集内的按下与松开，短按可见高亮；断线重连清除旧状态，录制按真实事件时间记录。
- 提供按键/方向帽/轴学习、轴反向、中心/扳机范围校准、独立摇杆与扳机死区，按设备保存配置。
- 明确开始后录制当前手柄，可用 Ctrl+Alt+F10 开始/结束；结束后导出中文 TXT。断连、切换或隐藏会自动结束并保留导出。
- 仍可分享一个 EXE，SDL 已内嵌，启动后释放到当前用户运行缓存。需要 .NET Framework 4.x、WebView2；请先退出旧版再启动。

**实体 Xbox / PS / 北通手柄及真实游戏尚未实测。** 已验证 SDL 原生初始化、模拟输入、校准、断连停止、界面切换和 TXT 下载，兼容范围按接口与模式说明，不代表每个型号已认证。详见[手柄使用说明](docs/手柄使用说明.md)。本功能用于显示和记录，不改变游戏键位，不包含回放。

## 桌面键盘与鸣潮专属录制

- 小人面前新增 26 个字母键的 QWERTY 键盘，额外显示空格和鼠标左右键，宽度与桌宠画布一致，使用圆润键帽、奶油色底板和原界面的暖色描边；按下高亮，松开恢复。
- 可切换为“鸣潮专属”：显示 1/2/3、Q/E/R、空格、鼠标左右键。计数器左侧的键盘图标可展开／收起，重新展开会恢复上次模式；设置中也可关闭键盘。
- 点击“开始录制”或按 **Ctrl+Alt+F10** 开始，再次触发结束。这个独立快捷键可在设置中修改，并参加已有冲突检测。
- **只录 1/2/3、Q/E/R、空格、鼠标左右键**。录制状态和时长始终在键盘下显示；没有自动开始或后台隐藏录制。
- 结束后点击“导出 TXT”。内容包含相对时间、按下/松开、按住时长。记录仅在本机内存中保留，不会自动上传；“清除”、退出或新一轮录制会清理上一轮数据。
- 键盘高亮复用原程序的 `key-press` / `key-release`；鼠标使用启动器本地通道，不可用时回退原程序的 `mouse-button` 事件。隔离浏览器已测试布局、事件适配和导出；真实游戏中的原生全局事件仍待实测。

## 库存分享

- 同版本修复：角色、配件和表情的图下注明各自的官方素材名称，不再把配件、表情统一显示为角色名；官方名称缺失时明确标注未加载。
- 一键读取当前账号已拥有的完整库存，按角色、配件、表情分区，每行 5 个。
- 使用原程序的背景纹理、四种稀有度底图和库存图片：Epic 彩色、Rare 紫色、Uncommon 蓝色、Common 绿色。
- 各分类内按稀有度从高到低、系列名称、角色名排序；名称按中文拼音自然顺序排列，同名按素材 ID 保持稳定顺序。
- 显示拥有数量、角色名和系列名；支持预览、保存 PNG、复制图片和取消生成。
- 不受当前筛选条件或滚动位置影响；素材加载失败会明确标记；特别大的库存会分段导出。

## 六槽表情快捷键

Ctrl+Alt+1～6 发送表情菜单中对应槽位当前装备的表情，无需展开菜单；更换装备后自动跟随。可在快捷键设置中逐项修改或禁用，支持冲突提醒，保留旧版自定义键位。复用原版鼠标发送流程，离线仅本地显示，联机送达仍由官方连接决定。

## 其他功能

- 默认显示器：保存启动时优先使用的屏幕，支持立即切换、断开回退主屏和重连恢复；保留临时切屏快捷键。详见[使用说明](docs/使用说明.md#默认显示器)。
- 设置面板请求取消置顶、显示在任务栏，点击外部保留面板，保留关闭按钮。
- 保留自动宝箱开关：默认关闭，倒计时结束至少等 5 秒，检查领取条件，失败后退避重试。
- 联机页的「仅显示自己」只影响本机显示，后来加入、重连、换房和重启都会遵循该设置。关闭后可逐人显隐。新版的「恢复显示全部」（旧版称「一键可见」）同时清除逐人隐藏。
- 自定义刷新、游戏模式、屏幕切换和桌宠显隐快捷键，提供冲突提醒，保留 PrtScr 截图键。
- 本地“+10000”按钮增加防连点保护：间隔至少 0.5 秒，保存未完成时重复点击会被忽略，不会积攒待执行点击；面板普通刷新合并为每秒最多 5 次。本地显示变化不代表服务器已接受或已发放奖励。
- 显隐、游戏模式及切屏保留官方 1.0.4 的原生快捷键机制；不再套用 1.0.2 的取消注册机器码补丁。若 F7/F8/F9 与其他软件冲突，请在官方快捷键区域修改或清空。

## 安装与使用

1. 退出正在运行的 WuwaTappo 或旧版修改程序。
2. 下载并运行 `Wuwatappo_Helper-<版本号>-Setup.exe`，选择安装目录。也可解压免安装包后运行带版本号的 EXE。
3. 登录并打开库存，等库存加载结束后点击“分享库存长图”。
4. 生成完成后点击“保存 PNG”或“复制图片”。

安装包默认安装到当前用户目录，无需管理员权限。请保留 Windows WebView2 Runtime。升级前退出程序；卸载入口在 Windows“已安装的应用”中。卸载不清理原程序的账号和偏好数据。

## 导出文件的保存位置

TXT 和库存 PNG 均通过内置 WebView2 下载，程序没有固定保存目录。未改下载位置时，通常在 Windows“下载”文件夹（`%USERPROFILE%\Downloads`）；如果“下载”已迁移或另存时选择了其他目录，以实际位置为准。

- 手柄 TXT：点击“导出手柄 TXT”后保存，文件名为 `Wuwa-手柄录制-<时间戳>.txt`。
- 鸣潮专属 TXT：点击“导出 TXT”后保存，文件名为 `Wuwa-操作录制-<时间戳>.txt`，可直接用记事本查看。
- 分享图片：在长图预览中点击“保存 PNG”，文件名为 `WuwaTappo-库存-<时间戳>.png`；分段图片需分别保存。
- “结束录制”“生成长图”不会自动保存文件；“复制图片”只写入剪贴板。

详细查找方法和注意事项见[使用说明：保存位置](docs/使用说明.md#txt-与分享图片保存在哪里)。

## 从本地原件构建

仓库包含辅助补丁与打包脚本，不提交原程序的解包代码、图片、账号文件或本机配置。

需要 Windows、Node.js 22 或更新版本、pnpm、PowerShell 7、Inno Setup 6（或兼容版本）、Windows .NET Framework C# 编译器，以及摘要匹配的 SDL3 3.4.18 x64 运行库（准备方法见[手柄说明](docs/手柄使用说明.md#开发构建与核验)）。

```powershell
pnpm install --frozen-lockfile
pwsh -File scripts/build.ps1 -SourceExe 'F:\WuwaTappo\WuwaTappo.exe' -IsccPath 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

脚本会核验原件摘要，提取构建所需资源并运行检查，默认输出完整版 EXE、安装包、免安装 ZIP、轻量版 EXE 和 SHA-256 校验文件到 `dist/local-1.0.4.5/`。迁移专项回归使用 `node scripts/test-v103-suite.cjs --ui`，需先构建。

安装 Edge 后，首次视觉回归先运行 `node scripts/prepare-ui-fixtures.cjs` 获取固定的公开测试素材，再运行 `pnpm test:migration`。逻辑测试使用仓库内的最小公开目录样本；视觉测试使用六个系列人物和三件配件，不依赖开发者本机缓存。测试使用独立临时配置，不读取用户真实操作。安装包文件测试入口为 `pwsh -File scripts/test-package.ps1 -DistributionDirectory ./dist/local-1.0.4.5`。
