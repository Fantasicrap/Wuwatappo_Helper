# 外观主题

打开「设置 → 互动与表情 → 外观主题 → 导入主题包」，选择 `aemeath.wttheme`、`denia.wttheme`、`phrolova.wttheme`。导入后立即应用，也可以在同一处切回原版暖色。已安装的主题包保存在 `%LOCALAPPDATA%\Wuwatappo_Helper\themes`，切换时桌宠窗口和面板窗口一起更新。主题包适用于完整版。

| 主题 | 内容 |
| --- | --- |
| 原版暖色 | WuwaTappo 原本的奶油色与棕色，不做任何改动。 |
| 爱弥斯（`aemeath.wttheme`） | 小爱粉配色、面板背景、隧者兵装和飞行雪绒播放器。 |
| 达妮娅（`denia.wttheme`） | 珍珠雾紫配色、拟态泡泡、角色动效和拉海洛方块。 |
| 弗洛洛（`phrolova.wttheme`） | 彼岸绯红配色、插画背景、波纹宝箱和 i弗TV 设置入口。 |

「外观主题」只提供当前主题的专属互动。爱弥斯主题显示「爱弥斯 · 隧者兵装」，弗洛洛主题显示「i弗TV」。切走主题会立即结束对应互动，切回后恢复原设置。

## 爱弥斯主题

配色取自角色的粉色头发和青色光效。界面里的奶油色、橙色和棕色换成对应深浅的粉色，原本的黄绿色强调色换成青色。灰色、红色、绿色、蓝色和稀有度颜色保持原样，所以报错提示和稀有度标记的含义不变。

面板内容区默认使用爱弥斯插画，保留半透明的粉白色蒙层以保证文字可读。「面板背景 → 选择图片」支持 PNG、JPEG、WebP、BMP 和 GIF，GIF 使用静态画面。图片在本机缩放保存，重启后仍生效。「恢复默认」可换回主题内置插画。自定义背景只用于爱弥斯主题的面板，桌宠窗口保持透明。

开启「用气泡显示输入」后，按键气泡变成粉色渐变，带一颗青色星光。每次按键气泡弹出、停留、再向上淡出，整个过程 1 秒，和气泡原本的显示时长一致。连续按键时动画从头重播。系统开启「减少动态效果」时不播放动画。

库存长图是导出给别人看的图片，仍按原版配色绘制。

选中爱弥斯主题后，在「外观主题 → 爱弥斯 · 隧者兵装」可给当前显示的爱弥斯桌宠添加伴飞机甲，默认关闭。待机悬浮、待机挥剑、自动环绕和输入联动都有单独开关。待机时随机播放约 1.6 秒的蓄势横扫，或约 2 秒的持刀旋身，光刃从剑柄展开并随握剑手移动。键盘、鼠标或手柄在 2.5 秒内按下 6 次，松手后触发一次环绕，快速触发间隔至少 8 秒。静置 18–24 秒也会环绕。机甲在弧线、Z 字和对角折返路线之间随机切换，经过角色上方和前方时始终朝向角色。核心发光与长按展翼也可各自关闭。

爱弥斯主题用浮金波纹和铸潮波纹替换两枚宝箱倒计时气泡。倒计时显示在波纹下方，到点后原位可领取，打开时图标化成星光散去。领取内容以桌宠实际奖励为准。

隧者兵装的「长按升空发射激光」和「敲击时召唤隧者大剑」可分别开关，大剑需要开启输入联动。键盘、鼠标或手柄长按 1.2 秒会触发激光，触发间隔至少 20 秒。机兵在左侧时，激光从机兵正下方扫到角色右上方，大剑落在角色右侧。机兵在右侧时镜像播放。每次满足条件的新按下有 1% 概率召唤大剑，触发后冷却 10 分钟，重启后继续计算。长按产生的重复按键和冷却期间的敲击不会重新抽取。完整触发条件见 [README](../README.md#隧者机兵动作条件)。

普通装备与图鉴试装按当前显示的角色外观识别，已核对经典、团团团团转、ARE、CHUBBY、像素和 Miratsu 六套爱弥斯外观。

点击计数栏的星星，会在桌宠旁弹出「飞行雪绒」播放器。再次点击星星或点击右上角可以收起。点击曲目名称展开列表，把鼠标放在列表上用滚轮浏览。默认曲目随爱弥斯主题包提供，打开播放器即可离线播放。齿轮设置可另选本地音乐文件夹。歌单末尾还提供《纸飞机》《靛青宇宙》《碎花》的官方试听入口。随包歌曲最终权利归歌曲作者和库洛游戏公司所有。

## 达妮娅主题

「珍珠雾紫」用鸢尾紫和浅蓝折光统一计数栏、输入映射与弹窗。左侧导航和内容区铺同一张背景，设置卡片保留半透明底色。达妮娅和爱弥斯分别保存自定义背景，「恢复默认」恢复当前主题的内置背景。

达妮娅主题与爱弥斯使用同款宝箱外观，左槽为浮金波纹，右槽为铸潮波纹。两枚宝箱到点后可点击，领取时化成星光。

| 动效 | 触发条件 |
| --- | --- |
| 拟态泡泡 | 默认启用。先在输入设置勾选「用气泡显示输入」，按键气泡就会使用珠光样式。 |
| 虚质之手 | 默认关闭。当前显示的角色为达妮娅时，长按键盘、鼠标或手柄约 0.8 秒，两只深紫色的手从两侧前探，朝镜头抓握后消散。两次相隔至少 8 秒。 |
| 剪纸小人 | 默认关闭。当前显示的角色为达妮娅时，1.4 秒内按下 3 次会触发牵手踏步和跳跃。两次相隔至少 9 秒。 |
| 生日蛋糕 | 默认开启。显示在达妮娅身旁，造型参考剧情中的柑橘奶油蛋糕，加上果片、糖饰和蜡烛。 |
| 吹蜡烛 | 默认开启。点蛋糕点亮蜡烛，再点一下吹灭。剪纸小人探头，人物右上方出现一句台词。 |
| 剪纸小人宝箱提醒 | 默认开启。箱子可领取时，纸人跑到相应的波纹旁敲两次。领取后，纸人在波纹旁停留，再淡出退场，整个退场过程约 2.4 秒。 |
| 日常台词气泡 | 默认关闭。可用 12 句原创随机台词，也可给键盘、鼠标及手柄按钮单独绑定台词。按键映射留在左侧，吹蜡烛和日常台词共享右侧气泡。 |
| 闲置动画 | 默认开启。键鼠和手柄停止输入 10 秒后触发一次，吹泡泡和剪纸小人环绕跳舞交替出现，每段约 3.9 秒。恢复操作后重新计时。 |

达妮娅按官方角色 ID 识别，也支持图鉴试装中正在显示的达妮娅。系统开启「减少动态效果」时显示定格。造型与动效参考[《鸣潮》官方过场《生日快乐》](https://www.youtube.com/watch?v=Qz2AWhLH3GE)和[《鸣潮》达妮娅战斗演示](https://www.youtube.com/watch?v=aKWE-ON3XSM)。

点击计数栏的星星，在独立窗口选择「经典下落」「拉海洛方块」或「拉海洛方块・逆转」。

「经典下落」使用自动落块和横向消行。A/D 或 ←/→ 移动，R 或 ↑ 旋转，↓ 下移，空格落到底，P 暂停。累计消除三行后，可按 B 吹泡泡清除最底一排。

两种拖放玩法都可选积分或奖章目标及难度，拥有各自的本机最高分。把一组方块拖到棋盘的空位，填满横行或竖列就会消除，同组方块全部用完后才会补充。[《鸣潮》3.2 活动说明](https://www.bilibili.com/opus/1183668937144926245) · [3.8 版本公告](https://wutheringwaves.kurogames.com/de/main/news/detail/5778)

按 1–3 选块，使用 WASD 或方向键移动预览，空格放置，P 暂停。「拉海洛方块」使用固定朝向，「拉海洛方块・逆转」可按 R 旋转，拖动时同样有效。每消除 3 条行或列可充满一次泡泡。按 B 只清除棋盘最底一排，上方方块留在原位。

本地达妮娅主题包的「泡影」背景由 [Hikaku 绘制](https://www.pixiv.net/artworks/144153156)。构建主题包时可用 `WUWA_DENIA_BACKGROUND` 指定 JPEG、PNG 或 WebP，以及 `WUWA_DENIA_BACKGROUND_CREDIT` 配置署名。缺省时使用程序绘制的珠光底色。

## 弗洛洛主题

在「外观主题」导入 `phrolova.wttheme`。暗酒红用于侧栏，灰粉用于卡片和计数栏，强调色用绯红。设置背景可自定义。本地测试包采用《冥府に沈む花》，插画作者为 おいろ。[Pixiv 原帖](https://www.pixiv.net/artworks/134265940)

两枚宝箱使用浮金波纹和铸潮波纹的造型，开启时使用绯红星光。选中弗洛洛后，从「外观主题 → i弗TV」打开设置。切换主题会结束正在播放的互动；切回后会读取已保存的 BE／HE 开关、台词和缚誓之核数量。[i弗TV 说明](i弗TV.md)

三个主题均在「外观主题 → 面板背景 → 素材署名」显示当前主题的署名。弗洛洛的左侧导航和内容区共用同一背景来源，导航上的半透明暗色蒙层用于提高文字对比度。

构建测试主题包时可用 `WUWA_PHROLOVA_BACKGROUND` 指定本地背景图，用 `WUWA_PHROLOVA_BACKGROUND_CREDIT` 配置署名。

## 实现方式

官方样式表不在补丁范围内，所以主题在运行时改写已加载样式规则里的颜色，不新增覆盖规则。这样选择器优先级和先后顺序与原版完全一致。每处改动都有记录，切回原版暖色时逐条还原。之后才加载的样式表也会被处理。

颜色换算规则在 `patches/theme.js` 的 `remap()`。爱弥斯的局部样式在同一文件，达妮娅的局部样式和动效在 `patches/denia-theme.js`，由本机 Helper 服务加载。

主题模块通过本机 Helper 服务读取已安装的主题包，按需读取图片、机兵和音乐。Helper EXE 保留可信的运行逻辑与小游戏窗口代码。

## 素材与构建

背景图和机甲来自仓库外的素材目录，默认是仓库同级的 `爱弥斯主题素材`。`scripts/build-theme-assets.cjs` 将处理后的素材输出到 `dist/theme-assets`：

- `aemeath-background.jpg`：缩放到 1280 像素宽的背景图。
- `aemeath-mech.webp`：由 `机兵概念/隧者兵装-Q版草图.png` 生成的透明机甲素材。
- `aemeath-toolbar.png`：用官方工具栏贴图生成的同色计数栏右半部分。
- `aemeath-tides.webp`：左浮金波纹、右铸潮波纹的宝箱图标，来源为 `机兵概念/波纹-Q版图标.png`。

默认背景是 `01_整体背景/Sanyue-Qiushi-粉色长椅.jpg`。可以用环境变量替换素材。

| 环境变量 | 作用 |
| --- | --- |
| `WUWA_THEME_MATERIALS` | 素材目录 |
| `WUWA_THEME_BACKGROUND` | 背景图片路径 |
| `WUWA_THEME_MECH` | 机甲透明图片路径 |
| `WUWA_DENIA_BACKGROUND` | 达妮娅背景路径 |
| `WUWA_DENIA_BACKGROUND_CREDIT` | 达妮娅背景署名 |

完整构建会在输出目录同时生成三份独立的 `.wttheme`。单独重建主题包可运行 `pwsh -File scripts/build-theme-packs.ps1 -OutputDirectory dist/theme-packs -SongsDirectory ../Songs`。素材缺省时仍可生成对应配色的主题包。

公开分发时如需省掉同人背景图，可使用 `-WithoutFanBackgrounds` 打包。主题会使用各自的默认背景配色，并保留自定义背景入口。

### EXE 图标

EXE、安装程序和快捷方式统一使用原版六档图标。主题包只切换程序内的外观。`scripts/test-icon.ps1` 核对各个图标帧。

## 授权提醒

同人图的出处见素材目录的 `素材索引.md`。公开发布带同人图的主题包需取得作者许可，或选用有授权的图片。

## 验证情况

配色换算、主题选择器和气泡动画有一个模拟页面可以直接在浏览器里打开查看。真实 EXE 里的效果需要本机构建后确认，包括两个窗口同步切换、背景图加载和图标显示。

## 主题包格式

`.wttheme` 是带有 `manifest.json` 的 ZIP 文件。清单版本为 1，当前支持 `aemeath`、`denia` 和 `phrolova`。清单记录主题版本、署名、启用的内置动效、音轨信息和素材 SHA-256。导入程序校验格式版本、文件数量、大小、类型和摘要，通过后才替换同名主题包。主题包仅接收数据和素材。
