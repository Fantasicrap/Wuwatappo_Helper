# 外观主题

打开「设置 → 互动与表情 → 爱弥斯主题与外观」可切换外观，默认是原版暖色。选择保存在本机，切换后桌宠窗口和面板窗口同时生效，无需重启。轻量版不包含主题。

| 主题 | 内容 |
| --- | --- |
| 原版暖色 | WuwaTappo 原本的奶油色与棕色，不做任何改动。 |
| 爱弥斯 | 小爱粉配色、面板背景图、带动画的粉色按键气泡。 |

## 爱弥斯主题

配色取自角色的粉色头发和青色光效。界面里的奶油色、橙色和棕色换成对应深浅的粉色，原本的黄绿色强调色换成青色。灰色、红色、绿色、蓝色和稀有度颜色保持原样，所以报错提示和稀有度标记的含义不变。

面板内容区默认使用爱弥斯插画，保留半透明的粉白色蒙层以保证文字可读。「面板背景 → 选择图片」支持 PNG、JPEG、WebP、BMP 和 GIF，GIF 使用静态画面。图片在本机缩放保存，重启后仍生效。「恢复默认」可换回主题内置插画。自定义背景只用于爱弥斯主题的面板，桌宠窗口保持透明。

开启「用气泡显示输入」后，按键气泡变成粉色渐变，带一颗青色星光。每次按键气泡弹出、停留、再向上淡出，整个过程 1 秒，和气泡原本的显示时长一致。连续按键时动画从头重播。系统开启「减少动态效果」时不播放动画。

库存长图是导出给别人看的图片，仍按原版配色绘制。

「爱弥斯 · 隧者兵装」可以给当前显示的爱弥斯桌宠添加伴飞机甲，默认关闭。待机悬浮、待机挥剑、自动环绕和输入联动都有单独开关。待机时随机播放约 1.6 秒的蓄势横扫，或约 2 秒的持刀旋身，光刃从剑柄展开并随握剑手移动。键盘、鼠标或手柄在 2.5 秒内按下 6 次，松手后触发一次环绕，快速触发间隔至少 8 秒。静置 18–24 秒也会环绕。机甲在弧线、Z 字和对角折返路线之间随机切换，经过角色上方和前方时始终朝向角色。核心发光与长按展翼也可各自关闭。设置控件跟随主题换色，机甲使用同一张立绘。

爱弥斯主题用浮金波纹和铸潮波纹替换两枚宝箱倒计时气泡。倒计时显示在波纹下方，到点后原位可领取，打开时图标化成星光散去。领取内容以桌宠实际奖励为准。

隧者兵装的「长按升空发射激光」和「敲击时召唤隧者大剑」可分别开关，需要开启输入联动。键盘、鼠标或手柄长按 1.2 秒会触发激光，触发间隔至少 20 秒。机兵在左侧时，激光从机兵正下方扫到角色右上方，大剑落在角色右侧。机兵在右侧时镜像播放。每次新按下有 1% 概率召唤大剑，触发后冷却 10 分钟，重启后继续计算。长按产生的重复按键和冷却期间的敲击不会重新抽取。

普通装备与图鉴试装按当前显示的角色外观识别，已核对经典、团团团团转、ARE、CHUBBY、像素和 Miratsu 六套爱弥斯外观。

点击计数栏的星星可打开或收起「飞行雪绒」播放器，面板会优先在桌宠周围有空位的位置展开。完整版构建时从工作区的 `Songs` 文件夹打包默认曲目，打开播放器即可离线播放。齿轮设置可另选本地音乐文件夹，每次启动应用后可重新选择。歌单末尾还提供《纸飞机》《靛青宇宙》《碎花》的官方试听入口。歌曲版权归原创作者及相关权利人所有。如有侵权，请通过 [GitHub Issues](https://github.com/Fantasicrap/Wuwatappo_Helper/issues) 联系下架。

## 实现方式

官方样式表不在补丁范围内，所以主题在运行时改写已加载样式规则里的颜色，不新增覆盖规则。这样选择器优先级和先后顺序与原版完全一致。每处改动都有记录，切回原版暖色时逐条还原。之后才加载的样式表也会被处理。

少数需要单独设计的位置（面板外框、标签、背景、气泡）写在 `patches/theme.js` 的 `aemeathCss` 里。颜色换算规则在同一文件的 `remap()`。

主题模块随公共脚本在每个窗口加载。背景图体积较大，放在本机 Helper 服务的 `ui.js` 里，不占用官方资源的压缩体积预算。

## 素材与构建

背景图、图标和机甲来自仓库外的素材目录，默认是仓库同级的 `爱弥斯主题素材`。构建时 `scripts/build-theme-assets.cjs` 将素材输出到 `dist/theme-assets`：

- `aemeath-background.jpg`：缩放到 1280 像素宽的背景图。
- `aemeath.ico`：16/24/32/48/64/256 六档圆角图标。
- `aemeath-mech.webp`：由 `机兵概念/隧者兵装-Q版草图.png` 生成的透明机甲素材。
- `aemeath-toolbar.png`：用官方工具栏贴图生成的同色计数栏右半部分。
- `aemeath-tides.webp`：左浮金波纹、右铸潮波纹的宝箱图标，来源为 `机兵概念/波纹-Q版图标.png`。

默认背景是 `01_整体背景/Sanyue-Qiushi-粉色长椅.jpg`，默认图标是 `04_Logo与图标候选/粉丝站-爱弥斯头像.png`。可以用环境变量换成别的图片：

| 环境变量 | 作用 |
| --- | --- |
| `WUWA_THEME_MATERIALS` | 素材目录 |
| `WUWA_THEME_BACKGROUND` | 背景图片路径 |
| `WUWA_THEME_ICON` | 图标图片路径 |
| `WUWA_THEME_MECH` | 机甲透明图片路径 |
| `WUWA_THEME_ICON_CROP` | 图标的方形裁剪范围，格式 `x,y,边长`，单位是原图像素 |
| `WUWA_ORIGINAL_ICON` | 设为 `1` 时 EXE 保留原版图标 |

例如用 Q 版插画的头部做图标：

```powershell
$env:WUWA_THEME_ICON='..\爱弥斯主题素材\04_Logo与图标候选\二创-Q版爱弥斯.jpg'
$env:WUWA_THEME_ICON_CROP='290,100,640'
```

素材缺失或处理失败不会中断构建。这时主题仍可选择，背景退回纯粉色，EXE 使用原版图标。处理结果写在 `dist/theme-assets/theme-assets.json`。

### EXE 图标

图标在构建时写入 EXE，和设置里选哪个主题无关。准备了素材就使用爱弥斯图标，安装程序和快捷方式跟着一起换。`scripts/test-icon.ps1` 核对 EXE 和安装程序里的图标帧与本次构建选定的图标逐字节一致，并在 `icon-verification.json` 里记录用的是原版还是主题图标。

## 授权提醒

素材目录里的多数同人图没有确认再分发授权，来源见素材目录的 `素材索引.md`。自己使用没有问题。公开发布带这些图片的 EXE 之前，请先取得作者许可，或者换成有授权的图片。

## 验证情况

配色换算、主题选择器和气泡动画有一个模拟页面可以直接在浏览器里打开查看。真实 EXE 里的效果需要本机构建后确认，包括两个窗口同步切换、背景图加载和图标显示。
