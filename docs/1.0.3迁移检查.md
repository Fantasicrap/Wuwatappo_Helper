## 已确认的变化

- 旧版的 21 条 API 路径在新前端中均可找到；这只是路径对比，不证明认证、参数、计数接收、奖励或服务器转发行为一致。
- 主面板迁移至 `/assets/index-pp8VWaUF.js`。
- 含库存面板的设置资源迁移至 `/assets/index-CiT_jZa7.js`。
- 包含开关面板窗口桥接逻辑的代码迁移至 `/assets/switchDisplayMonitor-B50jXMGD.js`。
- 新包体中未找到旧版 `btn-boost-clicks` 按钮锚点，不能继续依赖旧版隐藏按钮恢复方案。
- 旧版原生鼠标函数的字节校验不匹配。
- 旧版原生热键注册调用点的字节校验不匹配。
- 1.0.3 已提供官方 `ShortcutInput`、`app-shortcut`、`app-shortcuts-changed` 处理。自定义快捷键应接入新版官方机制，不能继续套用“跳过旧固定热键注册”的原生补丁。
- 1.0.3 增加“全屏进入游戏模式”选项，迁移时应保留该设置并避免与 Helper 的游戏模式热键重复触发。
- 原生鼠标分发函数已定位到候选文件偏移 `0x13ef0`；按旧函数长度解码后，其指令数量及结构均不同，不能仅给旧偏移统一加常数。
