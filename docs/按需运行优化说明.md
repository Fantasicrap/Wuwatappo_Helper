# 按需运行优化

仅供娱乐使用，创作者概不负责。

适配官方 1.0.3，Helper 版本仍为 1.0.3.2，本次在 GitHub 覆盖同版本附件。单文件名称为 `Wuwatappo_Helper-1.0.3.2.exe`，本地优化包位于 `dist/idle-optimized-1.0.3.2`。先从托盘完全退出其他版本再启动。前两版测试包保留。

## 运行条件

| 工作 | 开启条件 | 关闭后的行为 |
| --- | --- | --- |
| 小人拍手、长按手部状态、点击计数 | 原版正常运行条件 | 收起映射不会停用这条原版输入流程 |
| Helper 键鼠 HTTP 补充通道 | 26 键或鸣潮映射展开，且自己的桌宠显示 | 停止请求；恢复时跳过旧输入，晚到的请求结果不再更新界面 |
| Helper 额外全局键鼠钩子和按键状态扫描 | 最近 750 毫秒收到映射请求 | 到期卸载额外钩子，清理临时输入队列；只保留低频需求检查 |
| 映射自己的 DOM 键鼠监听 | 键盘映射正在显示 | 收起、切换手柄或隐藏桌宠时移除监听；配置事件监听仍保留，支持重新开启 |
| 键盘录制状态计时器 | 明确开始录制 | 结束或隐藏时移除计时器；普通映射显示不再每 200 毫秒刷新状态 |
| 手柄界面 HTTP 轮询 | 手柄映射展开且桌宠显示 | 停止轮询及隐藏界面的重复刷新，恢复显示时重新获取当前状态 |
| SDL 初始化、设备枚举和采样 | 最近 750 毫秒收到手柄请求 | 关闭设备、退出 SDL 采样并清空帧历史；不影响原版拍手 |
| 默认显示器拓扑轮询 | 用户明确指定主屏或某个显示器 | 选择“不指定”后取消额外的 5 秒轮询；原版切屏功能继续工作 |
| 辅助模块文本读取 | 首次需要该模块 | 原生服务在本次进程内复用同一份脚本文本，避免重复读取内嵌资源 |

“收起映射／不显示”会停用对应采集；仅隐藏“26 键／鸣潮专属／手柄、开始录制”等控制按钮时，键盘仍可见，映射保持运行。

## 其他改动

- 服务不可用时，键鼠与手柄请求改为约 1 秒后重试，避免每 40 毫秒重试。
- 原生键盘补充扫描只遍历支持的键，重复状态不会再不断创建键名字符串；无新事件的响应复用空数组。
- 切换、隐藏、退出后丢弃过期的异步结果，并处理监听订阅尚未完成就关闭的清理情况。
- 保留之前的隐藏房间图片卸载、隐藏成员跳过预加载和表情、界面图片按需加载，以及启动器流式解包。
- 未开始录制时不积累操作记录；映射显示仍需要保留当前按下状态。开始录制的独立快捷键继续可用。

自动宝箱仍使用原有倒计时任务并遵循至少 5 秒延迟；没有为了省资源停止房间连接、原版快捷键、计数保存或必要的倒计时。历史房间、库存生成等原本就只在用户打开或操作时运行的功能保持按需运行。

## 验证与限制

20 项脚本通过。隔离浏览器检查覆盖映射关闭无补充请求／状态计时器、模式切换、桌宠隐藏与恢复、键盘录制、手柄模拟录制及 TXT 下载、监听释放和截图。新增实际内置 Vue 渲染测试覆盖联机桌宠五次隐藏／显示、重新请求图片、加载占位切换及成员重进；原有固定结构优化标记已调整为支持图片卸载与恢复。原生检查覆盖采集需求的 750 毫秒到期规则、合成键鼠与 SDL 按下／松开、启动器、内嵌资源、图标、流式解包和隔离 HTTP 服务。

通过实际补丁函数的模拟输入验证：映射关闭时，原版拍手回调、松手回调与点击计数仍然执行；长按状态相关回归亦通过。这不等于真实游戏或实体手柄已经实测。

这批优化主要减少闲置 CPU 工作、定时唤醒和临时内存分配。原生需求检查和服务等待线程仍存在；WebView2 原有窗口及浏览器／GPU 基础占用不会因此全部消失。当前尚未在真实账号房间完成统一条件的前后内存对比，不承诺具体节省比例。
