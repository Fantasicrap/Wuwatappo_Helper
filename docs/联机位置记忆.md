# 联机桌宠位置记忆

仅供娱乐使用，创作者概不负责。

该功能已包含在 v1.0.3.4 中。运行 `Wuwatappo_Helper-1.0.3.4.exe` 即可使用。

## 使用

1. 从托盘完全退出旧版，再启动本版本。
2. 进入房间，把其他成员的桌宠拖到想要的位置并松开。初始自动布局后的坐标也会保存。
3. 完全退出再启动，使用同一账号进入同一房间；相同成员 ID 会恢复本机上一次保存的位置。成员离线后重新出现也走相同恢复流程。

位置从本版首次布局／拖放开始记录；旧版没有保存的历史坐标无法追溯。记录按当前账号、房间号、成员 ID 区分，成员更换角色仍使用该成员的位置。记录只保存在本机，不修改对方桌宠位置，不发送给服务器。

隐藏规则仍有效：恢复位置不会强制显示已隐藏的成员。显示图片的渲染修复已经包含在本测试版中。

## 保存与边界

- 在坐标落定且变化时保存，不新增定时器；拍手、表情等不带坐标的更新不触发位置写盘，相同坐标不会重复写入。
- 恢复时依据当前窗口尺寸换算，并使用原版屏幕边界限制；自动排列和显示器重整不会直接覆盖已经恢复的坐标。
- 存储键为 `wuwatappo-room-positions-v1`，保存在原程序同一 WebView 本地偏好中；所有账号和房间合计最多 1000 条，超限移除最早更新的记录。
- 无记录、记录损坏或存储不可用时沿用原版布局；清理应用偏好后需重新摆放。

## 验证

21 项脚本及启动器、图标检查通过。位置检查提取实际补丁的布局函数，覆盖新运行实例读回、账号／房间／成员隔离、自动排列、显示器重整、边界限制、自动位置保存、异常存储和记录上限。

实际内置 Vue 渲染测试验证：保存后的坐标对应页面 CSS 位置，移动后卸载并创建新场景仍能读回；同时保留五次隐藏／显示、图片重新请求、加载占位切换和成员重进检查。测试图片为离线 TEST 示例，不是用户真实库存素材。

真实账号联机房间、实体多屏和系统缩放尚未实机验证，需在本机试用确认。
