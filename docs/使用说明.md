# Wuwatappo_Helper 使用说明

**仅供娱乐使用，创作者概不负责。**

这是基于 WuwaTappo 1.0.3 的非官方辅助修改版本。原程序和所有角色、配件、表情及界面素材归各自权利人所有。

## 安装、启动与卸载

1. 先正常退出官方版或之前的修改版，避免单实例程序继续使用旧进程。
2. 运行 `Wuwatappo_Helper-1.0.3.1-Setup.exe`，阅读声明后选择安装目录，可选创建桌面快捷方式。
3. 安装完成后从开始菜单或桌面运行 `Wuwatappo_Helper`。默认安装在当前用户目录，不需要管理员权限。
4. 免安装用户可解压 `Wuwatappo_Helper-1.0.3.1-Portable.zip`，直接运行里面的 EXE。
5. 卸载前先退出程序，再到 Windows“设置 → 应用 → 已安装的应用”中卸载。本安装包不清理原程序账号数据和偏好。

官方内层 EXE 要求管理员权限；启动时如出现 Windows UAC 提示，需要由用户确认。取消时不会继续启动桌宠。安装无需管理员权限，安装与启动权限是两回事。

需要 Windows 10/11 x64 和可用的 WebView2 Runtime。原程序的登录、联网和官方素材服务仍需要正常工作。

## 26 键键盘与鸣潮专属

小人面前会显示一块与桌宠画布同宽的圆润键盘。默认是 26 个字母键，按 QWERTY 三行排布，底部另有鼠标左键、空格、鼠标右键；按下时高亮，松开后恢复。键盘跟随桌宠的位置和缩放。

点击键盘上方“鸣潮专属”，切换为 1/2/3、Q/E/R、空格及鼠标左右键的显示。点击“26键”返回完整字母键盘；点击“×”收起。计数器左侧新增键盘图标，点击即可展开／收起，并恢复上次的键盘模式；设置中的“桌面键盘映射”也可重新开启。展开时，快捷键提示与计数器会各占一行并保留间距。

选好模式后，可在设置的“桌面键盘映射”中点击“隐藏映射控制”，隐藏模式选择、录制和手柄设置按钮，仅保留映射图案；再次打开设置并点击“显示映射控制”即可恢复。录制进行中仍显示状态，结束后可重新显示控制并导出。该选择保存在本机。

“映射位置”按钮循环切换下方、左侧、右侧，设置保存在本机，对键盘和手柄映射均有效。展开时一起检查人物、计数器及映射的边界，保留小段边距；侧面空间不足时临时改为下方，仍保留选择的侧面偏好。当前按桌宠窗口可视区域计算，真实多屏、系统缩放和任务栏场景仍需实机确认。

桌宠内外的左键按下和松开均用于键位显示；鸣潮专属模式下也会写入录制。26 键模式只增加可视映射，录制仍通过鸣潮专属界面或录制快捷键开始。

## 录制与导出

1. 点击“鸣潮专属”的“开始录制”，或按 **Ctrl+Alt+F10**。快捷键开始录制时会显示鸣潮专属界面。
2. 键盘下方显示录制状态、经过时间与事件条数。录制范围仅为 **1、2、3、Q、E、R、空格、鼠标左键、鼠标右键**。
3. 点击“结束录制”或再次按快捷键。结束后点击“导出 TXT”保存本次操作。
4. 在设置的快捷键区域，可单独修改“鸣潮录制开始／结束”，支持组合键和冲突提示。

如果旧版本的某个自定义功能已占用 Ctrl+Alt+F10，会保留旧设置，并将新增录制快捷键暂时留空；此时可点击按钮录制，再自行设置新组合。

TXT 使用中文列名，包含开始时间（UTC）、总时长、事件条数及每次操作的相对时间、按键、按下／松开、按住时长和备注。同时按键分别记录，系统长按的重复通知会去重。时间以应用收到事件的单调时钟为准，不是游戏内部帧时间。

停止时仍按住的键会补充“停止录制时补记（非实际松开）”的结束标记，并注明原因，不会冒充真实松开事件。开始前已按住的键不会产生孤立的松开记录。点击本键盘上的按钮不会作为游戏操作写入记录。

“清除”删除本机内存里的记录。新一轮录制、退出应用也会清理上一轮数据，请先导出。达到 50,000 条附近的安全上限时会自动结束，并保留导出；最多再增加九个按住结束标记。隐藏或切换离开鸣潮专属也会结束录制，回到鸣潮专属可导出刚结束的记录。

记录不会自动上传，也不会读取文字内容、剪贴板或屏幕。本功能不包含操作回放。这个版本是预览版：高亮和录制依赖原程序已有的全局事件，真实游戏尤其独占输入场景尚未实测。

## 手柄

点击键盘工具栏“手柄”，显示完整手柄外形与对应按键。支持自动/Xbox/PS/Nintendo/通用标签，按下和松开高亮，双摇杆位置及扳机进度。设备名称按钮切换当前设备；“选项”提供死区、按键和轴学习、反向、中心及扳机两端校准。Share / Options 在图中用 − / ≡ 表示。

在手柄界面点击“开始录制”或按 Ctrl+Alt+F10，再次触发结束；点击“导出手柄 TXT”保存。只记录选中的手柄，不混入键鼠。断开、切换或隐藏会结束，停止时仍按住的键有明确补记。北通鲲鹏等第三方手柄优先用 PC/XInput 模式，具体操作、兼容路径与限制见[手柄使用说明](手柄使用说明.md)。实体手柄与真实游戏尚未实测。

新版 EXE 内嵌 SDL3 运行库，仍可单文件分享。启动时释放至 `%LOCALAPPDATA%\Wuwatappo_Helper\runtime\<版本及摘要>\`；请启动外层 Helper EXE，不要直接运行缓存中的原生程序。需 .NET Framework 4.x 和 WebView2。

## 库存长图

1. 登录账号，打开库存，等库存加载完成。
2. 点击“分享库存长图”。它会读取全部已拥有库存，不受当前类别、筛选和滚动位置影响。
3. 图片分角色、配件、表情三块，每行 5 个；使用原版背景、原版稀有度底图和原版库存图片。
4. 稀有度从高到低为 Epic → Rare → Uncommon → Common；同稀有度按系列名称、角色名排序，名称采用中文拼音自然顺序。
5. 图片显示数量、角色名和系列名。生成后可以保存 PNG 或复制图片；生成过程中可以取消。

素材加载失败时会显示占位和失败数量，关闭预览后重试即可。库存特别多、超出单张画布高度时会分成多张长图。长图不会自动上传或发送给其他人。

## TXT 与分享图片保存在哪里

程序通过内置 WebView2 的下载功能保存文件，没有写死保存目录，也不固定保存到 EXE 所在目录。未更改下载位置时，通常先到 Windows 的“下载”文件夹查找：

```text
%USERPROFILE%\Downloads
例如：C:\Users\<你的用户名>\Downloads
```

如果系统的“下载”文件夹已迁移，或下载时在“另存为”里选择了其他位置，请以实际下载位置为准。WebView2 的下载目录设置可跨会话保存，后续下载可能继续使用之前设置的目录。[Microsoft WebView2 下载目录说明](https://learn.microsoft.com/en-us/dotnet/api/microsoft.web.webview2.core.corewebview2profile.defaultdownloadfolderpath)

| 操作 | 保存结果与文件名 |
| --- | --- |
| 结束录制后点击“导出 TXT” | 下载 `Wuwa-操作录制-<时间戳>.txt`，使用 UTF-8 编码，可直接用记事本查看 |
| 手柄录制结束后点击“导出手柄 TXT” | 下载 `Wuwa-手柄录制-<时间戳>.txt`，包含按键、轴值和时间 |
| 长图预览中点击“保存 PNG” | 下载 `WuwaTappo-库存-<时间戳>.png`；分段图片另带 `-1`、`-2` 等页码，需要分别保存 |
| 长图预览中点击“复制图片” | 只复制到剪贴板，可粘贴到聊天或画图软件；不会自动生成本地 PNG 文件 |

结束录制只会保留内存中的记录，必须再点击“导出 TXT”才会请求保存；生成长图也只显示预览，必须点击“保存 PNG”才会请求保存。不要在导出前清除记录、开始新一轮录制或退出软件。

找不到文件时，先打开资源管理器的“下载”，按修改时间排序，或搜索 `Wuwa-操作录制-*.txt` / `WuwaTappo-库存-*.png`。重复保存的同名文件可能出现 `(1)`、`(2)` 等后缀；点击下载后仍需确认保存或下载完成。

## 设置窗口与截图

设置面板请求以非置顶窗口显示，并出现在任务栏；点击外部保留面板的旧窗口桥命令在官方 1.0.3 上是否受支持仍需实机确认。使用面板上的关闭按钮关闭。PrtScr 截图键会放行给系统，也可使用系统截图工具。

## 自动领取宝箱

在设置中打开“自动领取宝箱”。该功能默认关闭。倒计时结束后至少等待 5 秒，满足登录、网络和点击数等原有条件后才尝试领取。左右宝箱顺序处理，失败后等待 30 秒再重试。实际结果以服务器返回为准。

## 本地点击数按钮

“+10000”每次被接受时增加 10000 本地点击数，间隔至少 0.5 秒。按钮冷却或上一轮保存未完成时，重复点击会被忽略，不会排队在稍后补加。连点器持续点击也受主面板的同一保护约束。普通面板刷新每秒最多 5 次，合并为最新状态。

本地显示变化不代表服务器已接受计数或发放奖励。本次验证覆盖模拟高频事件、慢保存与刷新积压，未自动操作真实账号或复现原生卡死。

## 联机显隐与快捷键

- 1.0.3.1 中，显隐、游戏模式和切屏使用官方 1.0.3 的快捷键控件；下方 Helper 快捷键区管理刷新、录制及六槽表情。两组配置在保存时交叉检查冲突，PrtScr 留给截图。
- 联机页“一键不可见”和“一键可见”控制本机看到的其他成员桌宠，不修改其他人的设置。
- 设置中可自定义刷新、游戏模式、切换屏幕、桌宠显示/隐藏按键，支持 Ctrl、Alt、Shift 组合，并提示重复或常见冲突。
- PrtScr 保留给截图；录入快捷键后可保存、清空或重置默认值。
- 1.0.3.1 使用官方 1.0.3 的原生快捷键机制，不套用旧版取消热键注册的机器码补丁。F7/F8/F9 若与其他程序冲突，可在官方快捷键区域改为其他组合或清空。

## 历史房间

房间号旁点击“历史房间”。未在房间内时，加入区域也有这个按钮。列表按最近成功进入时间排序，同一房间只保留一条；当前房间以浅绿色标记。

- 点击当前房间 ID，提示“你已经在该房间”，不会退出或重复加入。
- 点击其他 ID，先请求退出当前房间，等待成功后再调用原有加入流程。退出失败会停止，加入失败会保留历史记录供以后重试，不自动反复请求。
- 切换过程中会显示进度并防止连续点击及手动创建/加入/退出并发。切换账号、退出登录或更新限制出现后，不继续下一步；账号切换会关闭历史面板。
- 仅在服务器成功确认成员快照后记录，保留本机该账号最近 100 个房间。安装这个版本以前未记录的房间无法追溯。
- 历史采用 `wuwatappo-room-history-v1:<账号ID>` 键保存在应用本机偏好，不保存密码或令牌，不自动上传。更换电脑或清除应用数据后需要重新积累；仅复制 EXE 不会复制历史。

房间已关闭、已满、网络异常或权限不足时，仍以官方服务的实际响应为准。历史面板和账号切换流程已用模拟状态验证，真实账号切换房间尚未自动化实测。

## 持续隐藏房间成员

点击“一键不可见”后，本次运行中其他成员默认隐藏，包括后来加入、重新连接、从离线恢复的成员，以及换房后的成员。点击“一键可见”解除；退出程序后恢复默认显示。只影响本机，不修改对方桌宠或服务器状态。当前账号自己的桌宠不受影响；若单独显示某个成员，该成员成为例外，再次“一键不可见”会清除例外。

## 六槽表情快捷键

默认 Ctrl+Alt+1～6 分别发送表情菜单中第 1～6 个槽位当前装备的表情。无需展开菜单，桌宠窗口不需要获得焦点。槽位顺序与原表情菜单的数据顺序一致；装备更换后快捷键随之生效。空槽位会提示“未配置”。

在设置的“快捷键设置”中找到“发送表情 · 槽位 1～6”，点击输入框录制新组合，点击“保存快捷键”生效；清除后禁用，恢复默认后也需要保存。六个槽位和已有操作一起检查冲突。旧版自定义组合若占用了新增默认键，会保留旧组合并停用冲突槽位的默认快捷键。

快捷键复用鼠标点击表情的原版处理：保留本地气泡、正常联机发送路径及原版限制。离线时只按原版逻辑显示本地表情；联机送达取决于房间连接与官方服务。快捷键编辑期间、文本输入框聚焦或强制更新限制时不会发送；长按不连续触发。组合键仍可能被其他软件占用。已验证模拟发送路径和设置界面，尚未进行真实账号联机送达测试。

## 库存欧非参考和饼图

点击“分享库存长图”后，程序根据已拥有的角色、配件、表情计算四档稀有度的件数和比例，包含重复物品，右上角显示四色饼图、百分比、件数与称号。左侧显示完整评语、合成次数读取状态和概率基准。多张长图使用同一份统计结果。

五档从非到欧为：雪豹卡卡罗の挚友、维神和羊咩的老熟人、索拉里普通漂泊者、小保底の常胜将军、库洛亲选天命之子。概率采用 Common 90%、Uncommon 9.5%、Rare 0.49%、Epic 0.01%。

这是库存构成的娱乐参考，合成、兑换、赠送都会影响结果，不能据此还原原始抽取运气。程序尝试通过原版账号信息请求读取明确命名的合成计数；接口不提供或读取失败时显示“未读取到，不能视为 0”。不把缺失次数当成零，也不猜测历史明细。生成时若切换账号，会停止并提示重新读取。

需要运行完整的新版外层 Helper EXE，以加载内嵌统计模块。离线模拟测试已通过；真实账号合成计数字段和真实联机环境仍需实机确认。详细公式、限制和评语见随包的《库存欧非判定.md》。
