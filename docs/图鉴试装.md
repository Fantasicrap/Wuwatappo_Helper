# 本地图鉴试装与本地表情栏

在“图鉴”页顶部勾选“启用图鉴试装”，即可点击未获得的角色、配件或表情。三类选择均在本机保存，不提交云端装备变更，也不修改官方库存或持有数量。

## 角色、配件

角色和配件覆盖当前电脑上的渲染选择，不向房间广播本地试装。继续使用官方公开素材目录、图片地址和普通素材加载流程，不需要下载全素材。

本地角色使用真实渲染 ID 和对应配件偏移。i弗TV 按当前本地角色与配件判定，因此可以选择未持有的弗洛洛及指定配件测试 BE／HE。其他角色或配件组合不会触发对应互动。

## 本地表情栏

首次编辑表情栏时，以当前云端表情栏为起点；选中的表情直接加入本地栏，最多六槽。再次点击已选中的表情可卸下。满六槽时，先卸下一格再添加。试装不需要先把表情装备到云端，也不需要登录。首次加载未缓存素材仍需连接公共素材服务。

本地表情栏用于桌宠的表情菜单、六槽快捷键以及“按键自动表情”的“装备栏表情”模式。选择后，打开自己桌宠的表情菜单即可点击发送。

发送沿用原版入口：离线可在自己的桌宠上播放；登录联机时由原版流程发送对应表情 ID，服务器是否接收或转发以真实结果为准。本功能不提交云端表情栏装备请求，不改变账号持有数量，也不修改官方库存分享结果。“随机已拥有表情”模式仍只读取账号实际库存。

## 保存与恢复

- 角色、配件及本地表情栏按账号分别保存，重启后保留。离线使用独立的本机记录。
- 关闭“启用图鉴试装”会恢复云端外观和表情栏；再次开启可恢复保留的本地选择。
- 点击“恢复云端外观”会清空本地角色、配件和表情栏覆盖，重新显示当前云端配置，不发送装备请求。
- 主动清空的本地表情栏与“跟随云端栏”分开保存，云端刷新不会把已清空的本地栏重新填满。

## 验证

隔离测试使用公开目录样本和实际构建的图鉴点击、表情栏计算属性、发送及快捷键代码，验证零云端装备修改、六槽限制、重启与账号隔离、离线本机播放、恢复及存储失败。发送入口使用模拟函数核对 ID，未替用户向真实服务器发送未持有表情。
