# 本地图鉴试装与云端表情栏

在“图鉴”页顶部勾选“启用图鉴试装”，即可点击未获得的角色、配件或表情。

## 角色、配件

角色和配件只覆盖当前电脑上的渲染选择，不提交角色／配件装备变更，不修改官方库存或持有数量，也不会向房间广播本地试装。仍使用官方公开素材目录、图片地址和普通素材加载流程，不需要先下载全素材。

本地选择按账号保存。关闭图鉴试装或点击“恢复云端外观”会立即恢复当前账号的云端外观，不会提交装备请求；重新开启可恢复上次保留的本地选择。恢复按钮会清空保存的本地角色／配件选择。

本地角色使用对应素材目录的真实渲染 ID 和配件偏移，不沿用云端角色的脸部／身体 ID。i弗TV 也按当前本地显示的角色判定：没有弗洛洛或两把剑时，可通过图鉴试装测试；试装其他角色或其他配件不会触发专属互动。

建议测试顺序：

1. 图鉴开启试装，选择弗洛洛任一系列皮肤。
2. 在配件页选择“共鸣回响·鸣式·利维亚坦”或“共鸣回响·芙露德莉斯”。
3. 设置中开启“i弗TV”，再分别开启需要的子功能。
4. 使用键盘、鼠标或手柄触发。掉落概率为 2%，开启掉落后显示当前数量。

## 表情

表情沿用正常云端表情栏流程，选择未获得表情时，只提交 `emote_asset_ids`，不把本地试装角色、配件作为装备变更提交。最多 6 槽，再次选择已装备的表情可卸下；没有登录时提示登录。不会给官方库存添加表情或伪造持有数量。

角色、配件是本地预览；表情选择会更改账号的云端表情栏，普通表情快捷键和发送继续使用该栏。真实服务器如果拒绝、过滤或未保留所选表情，会显示失败，客户端不会把拒绝伪装成成功。

用户已提供其环境中表情可被服务器接收的测试结果；本次实现另用隔离测试验证了请求字段、六槽限制、响应确认和错误分支，尚未替用户用真实账号提交未获得表情。不同版本服务器仍可能调整规则。

## 验证

隔离测试使用官方公开图鉴与素材目录，覆盖未获得卡片的可点击性、真实图鉴事件转换与主界面选择分流、角色／配件零装备请求、本地渲染 ID 与偏移、云端外观恢复、账号隔离、表情专用请求、六槽限制及服务端拒绝处理。
